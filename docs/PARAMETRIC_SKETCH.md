# Параметрика эскиза в КОМПАС + наш core

## Как работает КОМПАС
1. Эскиз на плоскости → `BeginEdit` → 2D-команды (`ksCircle`, `ksLineSeg`, …) → `EndEdit`.
2. **Управляющий размер** фиксирует геометрию; эскиз становится определённым/частично определённым.
3. **Внешние переменные** детали можно менять снаружи → пересчёт модели.
4. Ограничения (горизонталь, равенство, симметрия) — отдельно от «просто нарисованных» линий.

Без размеров эскиз часто **недоопределён**: построение может пройти, но редактирование и соседние фичи ломаются чаще.

## API
- API5: `GetParamStruct` + `ksLinDimension` / радиальные размеры — громоздко, зависит от typelib.
- API7: `ILineDimension`, `IParametriticConstraint`, переменные эскиза — предпочтительно для «настоящей» параметрики.

На установках без зарегистрированных библиотек типов (как в diagnose проекта) надёжнее **геометрия числами**; размеры — best-effort.

## Наш слой
```python
with part.sketch("xy") as sk:
    sk.circle(0, 0, 20)
    sk.dim_radial(0, 0, 20)   # может вернуть False — не ошибка сборки
part.extrude(sk, depth=50)
```

Агенту: размеры желательны, но не обязательны для успешного build.
