## Как лучше работать

1. Все изменения только в **agent-v2** (новые ветки не плодим).
2. Сначала задача текстом → `agent.build` → смотрим модель в КОМПАС.
3. Если не хватает API — дописываем `core`, потом промпт, потом снова `build`.
4. `main` не трогаем, пока сами не решите смержить.
