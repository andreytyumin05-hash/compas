## Исправления по твоим answers

Проблемы были:
1. LLM давал **лишний отступ** → `unexpected indent`
2. Отверстия на плите **без `part.cut`** → только круги в эскизе
3. Иногда кривой/пустой ответ модели

Сделано:
- нормализация отступов перед `exec`
- промпт: втулка = extrude + cut; отверстия всегда с cut
- авто-retry, если нет cut или валидация failed
- заготовка бота: `python -m bot`

## Команды

```powershell
# КОМПАС открыт
python -m agent.build "Плита 100x60x8, 4 отверстия диаметр 9 по углам отступ 10"
python -m agent.build "Втулка наружный 40 внутренний 20 длина 50"
```

## Telegram (заготовка)

1. @BotFather → токен
2. В `.env`: `TELEGRAM_BOT_TOKEN=...`
3. `pip install python-telegram-bot`
4. КОМПАС открыт на этом ПК
5. `python -m bot`
6. Напиши боту описание детали

Бот работает **только на машине с КОМПАС** (COM локальный).
