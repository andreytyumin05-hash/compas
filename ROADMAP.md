## Параметрика эскиза (в процессе)
| Этап | Суть | Статус |
|------|------|--------|
| A | Геометрия числами (circle/rect + extrude) | ✅ |
| B | Best-effort размеры в эскизе (`sk.dim_linear` / `dim_radial`) | ✅ API заложен, на ПК может вернуть False |
| C | Управляющие размеры + внешние переменные детали | ⏳ нужен живой v23 + SDK |
| D | Ограничения (горизонталь, равенство, симметрия) | ⏳ API7 constraints |
| E | Перестроение по изменению переменной | ⏳ после C |

**Зачем размеры:** закрытый эскиз стабильнее, можно менять Ø/длину без перегенерации всего кода.

**Почему сложно:** API5 `ksLinDimension` + `GetParamStruct` без зарегистрированной typelib на части машин падает; полноценная параметрика часто через API7 `IParametriticConstraint` + переменные.

## Чертёж → признаки
- Пунктир ≠ контур ✅ (промпт vision)
- Массивы PCD ✅
- Скругления/фаски/канавки ✅ (если LLM не упростит)
- Эскиз на грани тела (не только xy/xz/yz) ⏳

## Desktop-приложение
`desktop/app.py` — простое окно: задача → build → лог.
Обновления: кнопка «Проверить обновления» открывает GitHub ветку; при желании позже — `git pull` или GitHub Releases + версия в `VERSION`.

**Стратегия версий:** не тащить «вечный exe». Либо:
1. Ярлык на `python -m desktop` из git-клона (обновление = `git pull`), либо
2. Releases с номером версии + ручная/полуавтоматическая замена.
